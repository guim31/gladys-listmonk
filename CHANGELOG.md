# Changelog

All notable changes to this integration are documented in this file. The format
follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project
uses [semantic versioning](https://semver.org/).

Describe each change under `## [Unreleased]` as you make it. The Release
workflow moves that section under the version it ships, and the section becomes
the notes of the version's GitHub Release.

## [Unreleased]

### Added

- The Listmonk instance as a device: reachable, subscribers, blocklisted,
  new subscribers and unsubscriptions of the day, messages sent, the current
  campaign with its status and progress, open and click rates of the last
  campaign sent.
- One device per mailing list added from the Discover tab: subscribers and
  unsubscribed.
- Scene triggers: new subscriber (once per list joined), unsubscription,
  campaign finished.
- Scene action "Start or pause a campaign", refused until allowed in the
  configuration.
- Dashboard widget: subscribers, newcomers and departures of the day, and the
  latest campaigns.
- Texts and documentation in English, French, German and Spanish.
